# Kazakhstan Green Energy Reserve

«Мирный» жел электр станциясы (Жамбыл облысы, Мойынқұм ауданы) негізінде ұсынылған жел, күн және аккумулятор гибридті энергия кешенінің сайт-моделі. Сайт Hornsdale Power Reserve (Оңтүстік Австралия) сайтының құрылымы үлгісімен жасалған.

- **Жобаны құрастырған:** Ерәділова Данайым Мұратқызы
- **Ғылыми жетекшісі:** Ниханбаева Әсел Қуанышқызы

## Сайттағы бөлімдер
- Жоба туралы және негізгі деректер
- Жоба моделі: «Мирный» базалық жобасы мен KGER моделін салыстыру
- 48 сағаттық деректер графигі (модельдік симуляция)
- Технология және бес жаңалық: күн станциясы, аккумуляторды жетілдіру, ЖИ арқылы басқару, экологиялық мониторинг, электр желілерін жаңғырту
- Пайдасы, жоба кезеңдері, жиі қойылатын сұрақтар

## GitHub Pages-те жариялау
1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `kazakhstan-green-energy-reserve`), **Public** етіп қойыңыз.
2. **Add file → Upload files** арқылы `index.html`, `README.md` және `.nojekyll` файлдарын жүктеп, **Commit changes** басыңыз.
3. **Settings → Pages** бөлімінде *Source*: **Deploy from a branch**, *Branch*: **main**, папка: **/ (root)** таңдап, **Save** басыңыз.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<сіздің-логин>.github.io/kazakhstan-green-energy-reserve/`

## Ескерту
Оқу-зерттеу жобасы, ресми сайт емес. Базалық деректер ашық дереккөздерден алынды (TotalEnergies, Central Asia Climate Portal, ESS News). Күн станциясының қуаты, кеңейтілген аккумулятор және CO₂ есебі — шартты болжамдар; графиктегі деректер — симуляция.
